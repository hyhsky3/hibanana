# 图床功能集成指南 (ImgBB 版)

本指南旨在说明如何将本项目中的图床（图片上传）功能快速迁移到其他项目中。该功能基于 **ImgBB** API，支持图片转 Base64 上传，并提供了后端代理和前端直连两种模式。

---

## 1. 准备工作

1. **获取 API Key**: 
   - 访问 [ImgBB 官网](https://imgbb.com/) 注册账号。
   - 在 [API 文档页面](https://api.imgbb.com/) 获取你的免费 API Key。
2. **安装依赖**:
   - 项目需支持 `axios` (前端) 或 `fetch` (后端)。
   - `npm install axios`

---

## 2. 后端代理实现 (推荐)

使用后端代理可以有效隐藏你的 API Key，防止被他人恶意获取。

### 代码实现 (`api/upload.js`)
适用于 Vercel, Netlify, Cloudflare Functions 或 Express 等环境。

```javascript
// 后端 API 处理器
export default async function handler(req, res) {
    if (req.method !== 'POST') {
        return res.status(405).json({ message: 'Method Not Allowed' });
    }

    try {
        const { base64 } = req.body; // 接收前端传来的 base64 数据
        if (!base64) {
            return res.status(400).json({ message: 'Missing base64 data' });
        }

        // 剔除 Data URL 前缀 (ImgBB API 只接受纯 base64)
        const cleanBase64 = base64.replace(/^data:image\/\w+;base64,/, "");

        // 从环境变量获取 Key
        const apiKey = process.env.IMGBB_API_KEY;
        
        if (!apiKey) {
            return res.status(500).json({ success: false, error: 'Missing API Key' });
        }

        // 发送到 ImgBB
        const response = await fetch(`https://api.imgbb.com/1/upload?key=${apiKey}`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
            body: new URLSearchParams({ image: cleanBase64 })
        });

        const data = await response.json();

        if (data.success) {
            // 返回 ImgBB 生成的直链 URL
            return res.status(200).json({
                success: true,
                url: data.data.url
            });
        } else {
            return res.status(500).json({ success: false, error: '上传至 ImgBB 失败' });
        }
    } catch (error) {
        return res.status(500).json({ success: false, message: error.message });
    }
}
```

## 3. 前端集成实现

前端部分包含文件处理工具和上传逻辑。

### 3.1 工具函数
在上传前，通常需要将 `File` 对象转换为 `Base64` 字符串。

```javascript
/**
 * 将 File 对象转为 Base64 (纯数据)
 */
export const fileToBase64 = (file) => {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result.split(',')[1]);
    reader.onerror = reject;
    reader.readAsDataURL(file);
  });
};

/**
 * 压缩图片并转为 Base64
 */
export const compressImage = (file, maxWidth = 1024, maxHeight = 1024, quality = 0.8) => {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.readAsDataURL(file);
    reader.onload = (event) => {
      const img = new Image();
      img.src = event.target.result;
      img.onload = () => {
        const canvas = document.createElement('canvas');
        let width = img.width;
        let height = img.height;
        if (width > height) {
          if (width > maxWidth) { height *= maxWidth / width; width = maxWidth; }
        } else {
          if (height > maxHeight) { width *= maxHeight / height; height = maxHeight; }
        }
        canvas.width = width;
        canvas.height = height;
        const ctx = canvas.getContext('2d');
        ctx.drawImage(img, 0, 0, width, height);
        const dataUrl = canvas.toDataURL('image/jpeg', quality);
        resolve(dataUrl.split(',')[1]); // 返回不带前缀的 base64
      };
    };
  });
};
```

### 3.2 上传逻辑
包含“代理上传”和“失败回退直连”的双重保障逻辑。

```javascript
import axios from 'axios';

/**
 * 上传图片到 ImgBB
 * @param {string} base64Data - 纯 Base64 数据 (不带前缀)
 */
export const uploadToImgBB = async (base64Data) => {
  try {
    // 1. 优先尝试后端代理接口 (安全性高)
    const response = await axios.post('/api/upload', {
      base64: base64Data
    });
    return response.data;
  } catch (error) {
    // 2. 如果后端接口不可用，尝试前端直接调用 (需配置 VITE_IMGBB_API_KEY)
    console.warn('后端代理不可用，尝试直连 ImgBB');
    const IMGBB_KEY = import.meta.env.VITE_IMGBB_API_KEY;
    
    if (!IMGBB_KEY) return { success: false, error: '未配置 API Key' };

    const formData = new FormData();
    formData.append('image', base64Data);
    
    const directRes = await axios.post(`https://api.imgbb.com/1/upload?key=${IMGBB_KEY}`, formData);
    return {
      success: true,
      url: directRes.data.data.url
    };
  }
};
```

## 4. 环境配置 (.env)

为了使功能正常运行，请在项目的 `.env` 文件中配置以下变量：

```env
# 后端使用的 Key (隐私级别高)
IMGBB_API_KEY=你的_IMGBB_API_KEY

# 前端备用 Key (可选, 变量名通常以 VITE_ 或 NEXT_PUBLIC_ 开头)
VITE_IMGBB_API_KEY=你的_IMGBB_API_KEY
```

## 5. 使用示例

```javascript
async function handleFileUpload(event) {
  const file = event.target.files[0];
  if (!file) return;

  // 1. 转换或压缩
  const base64 = await fileToBase64(file);
  
  // 2. 上传
  const result = await uploadToImgBB(base64);
  
  if (result.success) {
    console.log('图片直链:', result.url);
    alert('上传成功！');
  } else {
    console.error('上传失败:', result.error);
  }
}
```

---

## 6. 注意事项

1. **纯 Base64**: ImgBB API 要求上传的 `image` 参数是不带 `data:image/jpeg;base64,` 前缀的纯字符串。
2. **跨域问题**: 如果直接从前端调用 ImgBB，它通常支持 CORS。但如果使用后端代理，请确保你的服务器配置了正确的 CORS 响应头。
3. **大小限制**: ImgBB 免费版对单张图片大小有限制（通常为 32MB），建议在前端进行压缩。

---

## 7. 部署建议

- **Vercel**: 将 `api/upload.js` 放在项目根目录的 `api/` 文件夹下，Vercel 会自动将其识别为 Serverless Function。
- **Netlify**: 如果使用 Netlify，建议将 `api` 文件夹重命名为 `netlify/functions`，并根据 Netlify 的函数规范调整导出格式（通常是 `exports.handler = async (event, context) => { ... }`）。
- **Cloudflare Pages**: 可以使用 `functions/api/upload.js` 来实现类似的后端逻辑。
